# Contrôle visuel des rushes de démonstration

Ces quatre planches proviennent des rushes Pexels sélectionnés dans `rushes/manifest.json`. Elles ont servi à vérifier que chaque média correspond réellement à la scène attendue avant le rendu : ingrédients, geste, dressage et plat prêt.

Les MP4 bruts restent hors Git et hors Release. Les planches sont des preuves de sélection de basse définition; la provenance et la licence sont documentées dans `docs/LICENCES_RUSHS.md`.
