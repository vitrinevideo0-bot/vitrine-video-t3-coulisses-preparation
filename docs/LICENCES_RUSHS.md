## Usage T3

Les fichiers bruts servent uniquement à démontrer le moteur silencieux. Ils ne sont ni suivis par Git, ni publiés dans les artefacts ou Releases. Le workflow GitHub les télécharge à la demande, vérifie leur SHA-256, crée un montage fortement transformé, puis publie seulement le rendu composite et ses rapports.

Aucune personne visible n’est présentée comme soutenant Vitrine Vidéo ou un commerce réel. Les données commerciales affichées sont explicitement marquées comme données de démonstration.
